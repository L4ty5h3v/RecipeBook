# Recipe Book QA

Небольшое веб-приложение для управления продуктами и блюдами по требованиям задания.

## Что есть в проекте

- сервер на Python стандартной библиотеке;
- JSON API для продуктов и блюд;
- хранение данных в файле `data/db.json`;
- веб-интерфейс на статике;
- базовые unit-тесты для ключевых бизнес-правил.

## Запуск

```bash
python3 run.py
```

После запуска приложение доступно по адресу [http://127.0.0.1:8080](http://127.0.0.1:8080).

## Тесты

```bash
python3 -m unittest discover -s tests
```
